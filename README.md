# Quiz Game

## Description
A C++ console program that asks the user 5 different multiple choice trivia questions and displays the results at the end.

## How to Run
1. Open the project folder in Visual Studio.
2. Press Ctrl+F5 to build and run.
3. Input A, B, C, or D as prompted.

## Sample Input / Output
Input:
  What season of the year is referred to by 2 different names?
  A) Summer
  B) Fall
  C) Winter
  D) Spring
  Your answer: B
Output:
  For question 1, you answered B.
  You were CORRECT!
  The correct answer was B.
